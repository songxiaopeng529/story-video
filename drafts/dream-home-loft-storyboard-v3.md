# 《第一次看房，就不想走了》分镜脚本 V3 · 60 秒

## 生成前必读 · 全片音频一致性（严格遵守）

> 以下是硬性约束，不是可选建议。任意一项不满足，成片都视为不合格。

1. **三段视频只生成纯画面。** Clip A、B、C 不得各自生成旁白或背景音乐；如果视频模型自动附带声音，剪辑时必须全部静音并丢弃，不能混入最终成片。
2. **人物旁白必须来自同一条完整母带。** 全片始终使用同一个真人，或同一个 TTS 模型、同一个 voice ID 和同一份声音参考；语言、口音、语速、音高、情绪、响度、麦克风距离、混响与降噪设置全部锁定，禁止第一段一个声音、第二段换成另一个声音。
3. **优先一次性录制或生成完整 60 秒旁白。** 先把全文做成一条连续语音，再按画面时间轴对齐；不要把三段旁白分别生成，因为即使 voice ID 相同，也可能出现音色、语气和音量漂移。
4. **背景音乐全片只使用同一个音频文件。** BGM 从 00:00 连续播放到 01:00，20.0s 和 40.0s 处不能重新起播、换曲或重新生成；BPM、调性、乐器、旋律、音色和整体响度都必须连续。
5. **先拼画面，最后统一混音。** 三段画面连接完成后，再一次性铺入完整旁白母带、完整 BGM 和统一室内环境底噪；不得分别导出三段带声音的视频后再拼接。
6. **声音切点必须隐藏。** 20.0s 和 40.0s 两个画面切点都安排在旁白停顿处，只允许连续脚步声、衣料擦镜声或房间底噪跨过切点；BGM 的节拍和尾音必须无缝延续。
7. **交付前重点监听两个拼接区间。** 反复检查 19.5s–20.5s、39.5s–40.5s：人物音色、语速、音高和音量不能发生变化，BGM 不能跳拍、断拍、变调或突然变响；发现任何变化必须返工，不能用短淡入淡出掩盖不同声音。

## 成片方案

- 总时长：严格 60.0 秒。
- 生成拆分：3 段 × 20.0 秒；每段都低于模型单次 30 秒上限。
- 叙事方式：第一人称看房，伪一镜到底；观众就是来看房的人，画面中不出现房产经纪人或其他人物。
- 推荐画幅：16:9、30fps，与参考图一致，最利于保住楼梯、厨房、沙发和落地窗之间的空间关系。若主发抖音或小红书，需要单独重构 9:16 版本，不建议从横版成片直接硬裁。
- 语气：像朋友带朋友看自己刚发现的房子，轻松、自然、有一点心动；不要广告腔，不报面积、价格或虚构参数。
- 核心路线：黑色入户门 → 挑空全景 → 楼梯下电脑桌 → 开放式厨房与餐吧 → 弧形沙发 → 落地窗城市景观 → 左侧楼梯 → 二层卧室 → 开放衣柜 → 玻璃栏杆回望整屋。

## 空间与镜头连续性硬约束

1. 全片始终是同一套双层 Loft：黑色入户门在一层中左，奶油白厨房与大理石岛台在中央，电脑桌在左侧楼梯下，弧形米白沙发和落地窗在右侧，卧室在二层中央，开放衣柜在二层右侧。
2. 镜头高度固定在约 1.60–1.68 米，等效 24–28mm 广角；步速慢而稳定，只保留很轻的呼吸起伏，不做夸张跑动、漂浮、穿墙或突然瞬移。
3. 暮色和室内暖光保持一致。三段之间不能突然从傍晚变成夜晚，窗外城市灯光只能极轻微变亮。
4. 家具、门窗、楼梯级数、扶手方向、玻璃栏杆、吊灯数量和橱柜分区不得跨段改变；不新增人物、宠物或装饰品。
5. AI 生成画面中不直接生成字幕。旁白、字幕、标题和结尾提问全部在剪辑阶段叠加，避免乱码和跨段样式漂移。
6. 每段生成完先导出最后一帧；下一段优先以上一段最后一帧作为起始帧，同时继续使用原始 Loft 图片作为空间结构参考。

6. 最后统一加入旁白与字幕。旁白句子不跨 20.0s、40.0s 两个切点；切点处只保留脚步或擦镜声。
7. 若某段生成后结构漂移，只重做该 20 秒段；不要靠后期变形硬救楼梯、门窗或家具位置。
