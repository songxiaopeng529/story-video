# Loft 风格图鉴 · 现实 20 种 + 想象 28 种

## 数量说明

上一轮实际列出了两组内容：

- 现实中可装修落地的风格：20 种。
- 想象、抽象与理想型风格：28 种。
- 本文件共收录 48 种；用户提到的“28 种”对应第二组想象型风格。

## 使用方法

- **现实型**主要改变材料、配色、家具、灯光和局部结构，适合制作“看起来真的能住”的效果图。
- **想象型**会改变自然环境、重力、时间、尺度或空间规律，适合梦想住宅、概念短片和强视觉内容。
- 选择风格时先定一个主风格，再从另一个风格中借 10%–20% 的细节。不要把三四种强风格平均混合，否则空间会失去辨识度。
- “改造强度”表示相对当前奶油轻奢 Loft 的变化：低 = 换软装与表面；中 = 定制家具或局部结构；高 = 重构空间或物理规则。

## 建议的混合公式

混合时保持“一个主风格 + 一个辅助机制”，不要平均混搭：

1. **宋式新中式 80% + 云海悬浮 20%**：现实材料与梦境窗景结合，温柔、不俗套。
2. **中世纪现代 80% + 巨树共生 20%**：胡桃木家具与贯穿两层的自然结构结合。
3. **Art Deco 85% + 昼夜共存 15%**：都市奢华空间中让一层黄昏、二层星夜共存。
4. **粗野主义 80% + 室内峡谷 20%**：混凝土体块与水雾岩壁结合，像私人美术馆。
5. **70 年代太空时代 80% + 轨道空间站 20%**：可居住的复古未来住宅，不做冰冷科研舱。
6. **暗黑学院 85% + 梦境图书馆 15%**：现实书房逐渐延伸成没有尽头的知识空间。
7. **热带现代 80% + 太阳朋克 20%**：植物度假住宅加入未来生态循环系统。
8. **地中海洞穴 85% + 镜面水境 15%**：圆弧白墙与浅水倒影结合，安静而超现实。

## 选择检查表

选择下一套风格前，只需确认四件事：

1. 更想要“真的能装修”还是“像梦一样无法复制”？
2. 最希望观众记住楼梯、窗景、卧室还是厨房？
3. 氛围更接近温暖、神秘、震撼还是安静？
4. 是否允许改变建筑结构，还是只能替换装修与家具？
