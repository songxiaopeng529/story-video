# 《梦想中的小家》分镜脚本 V1 · 15 秒治愈系动画短片

## 创作简报

- 目标：用一束光的"游历"，带观众逛完一栋梦想中的 LOFT 切面小屋，让 20–35 岁观众产生"想住进去"的向往，愿意收藏并在评论区写下自己的梦想小家
- 受众：20–35 岁城市青年、租房与通勤人群；常在夜间刷短视频，对"属于自己的小空间"有补偿性想象
- 平台 / 形式 / 预计时长：抖音 / 9:16 竖屏 / 1080×1920 / 30fps / 严格 15.0 秒（竖屏天然适合高挑的 LOFT 切面构图）
- 核心主张：有书、有光、有热气腾腾的日子——家不在大小，在每一处都有人生活的痕迹
- 叙事结构：夜色中显现小屋 → 光点进入卧室 → 穿过阅读室 → 掠过客厅与厨房 → 拉远定格，小屋在星空下亮起
- 关键假设：
  - **未收到参考图**：本次消息中未附上图片，结构按"经典 LOFT 娃娃屋式切面"（上中下三层，正面剖开可同时看到全部房间）设计；拿到参考图后可对齐楼层与房间位置
  - 全片无真人出镜；唯一"活物"是卧室里睡觉的小猫；15 秒靠物件与光影叙事，不用对白剧情
  - 画风为原创手绘水彩 + 彩铅肌理的治愈系动画，**只借鉴吉卜力式的高描述性特质**（自然光、植物与生活细节、留白呼吸），不声称复刻宫崎骏或吉卜力画风，不复刻任何经典角色、场景或道具

## 视觉与风格规范

- 风格锚点：手绘水彩平涂 + 铅笔线稿肌理；夜色深蓝紫底 + 室内琥珀暖光，形成"外面安静、里面温暖"的对比；云层蓬松、植物茂密、物件有使用痕迹
- 小屋设定（全片一致，建议先生成一张结构设定图 `loft-cutaway-design-sheet.webp`）：
  - 三层切面结构，正面剖开像立体贺卡 / 灯箱；左侧外挂楼梯连通楼层
  - 顶层阁楼：卧室（圆窗、小床、格纹被、床头灯、猫）＋ 一小角衣柜
  - 中层：阅读室（整面书架墙、飘窗软垫、旧地球仪、垂吊暖灯、摊开的书）
  - 一层：开放式客厅 + 厨房（矮沙发、木桌上半杯热茶、窗边绿植、水壶、小画、玄关鞋与伞）
  - 屋外：小烟囱冒细烟、爬藤植物、门口花架；周边为夜空、云与萤火虫
- 连贯线索：一颗萤火光点从外飘入，依次游历各层，是镜头运动的"导游"
- 配色：夜蓝 `#2A3550` 系 / 暖琥珀 `#F2A65A` 系 / 木色与奶油白；室内光溢出窗外形成柔和光晕
- 文字规范：全片只有开头小标题与结尾大字，无贴纸、无箭头、无解释卡；字幕不遮挡屋内关键细节

## 制作提示

- 人物 / 场景 / 道具：无人物（可选：最终镜窗内加一个极小的读书剪影）；三层小屋 + 外挂楼梯；猫、书、地球仪、台灯、茶、水壶、绿植、伞、拖鞋
- 素材生成顺序（AI 生成流程建议）：
  1. 先出风格锚点图（夜色蓝 + 琥珀暖光的治愈系水彩小屋）
  2. 再出 `loft-cutaway-design-sheet.webp` 结构设定图，锁定三层布局、楼梯位置、家具与物件位置
  3. 五个分镜全部以该设定图为参考图生成，保证切面结构、家具颜色、猫的位置全片一致
- 运镜：建议做"伪一镜到底"——由萤火光点引导的连续运镜，五个镜头之间用光点运动匹配衔接；若分段生成，切点前后各保留光点在画面中的连续位置
- 声音重点：八音盒 / 钢琴 BGM 一条铺满 15 秒，不换曲；环境声保留风铃、翻书页、水壶轻鸣、猫呼噜、虫鸣
- 时长控制：每镜 3.0 秒共 15.0 秒；旁白约 45 个汉字，按舒缓情绪语速约 15 秒，留出生活声与定格呼吸
- 无障碍：旁白配字幕；核心信息不依赖文字也能看懂（暖光、物件细节本身叙事）
- 同质化反例：不要蓝紫霓虹 AI 渐变、不要 3D 渲染感、不要豪华大宅或极简性冷淡风、不要贴纸与箭头标注
