# 三套原创 Loft 空间布局方案

本轮不沿用既有 Loft 外壳，直接从建筑剖面、卧室数量和家庭动线重新设计。三套方案采用不同居住人群与空间组织逻辑，生成图统一使用暖调、雕塑感现代住宅材质与完整三分之四剖面视角，以便横向比较。

## 方案一：月相回廊 Loft

**定位**：情侣或一人长期居住，兼顾亲友留宿  
**面积与层高建议**：约 90–110 ㎡，净高约 6.6 m  
**配置**：2 卧、2 卫、1 个工作位、1 个主卧衣帽间

### 建筑与布局

- 建筑外壳为圆角长方体，南侧设置双层弧形落地窗，北侧设置连续设备与收纳墙。
- 一层由玄关、客房兼工作室、客卫、弧形开放厨房、半圆卡座餐区和双层挑空客厅组成。
- 客房采用隔音半透明移门和隐藏床柜，平日作为独立工作室，来客时转换为完整卧室。
- 二层夹层覆盖约 55% 面积，设置主卧、步入式衣帽间、主卫和悬挑观景回廊。
- 主卧朝向落地窗，以矮墙和可调雾化玻璃控制开放度；主卫与一层客卫垂直叠放。

### 核心空间语言

一条珍珠白弧形构件从玄关开始，依次成为收纳墙、厨房界面、楼梯侧墙、二层栏板，最终弯成主卧床头。圆月形壁洞、弧形窗影和暖光接缝共同形成“月相回廊”。

### 生活动线

入户 → 玄关收纳 → 客房／客卫 → 弧形厨房 → 卡座餐区 → 挑空客厅 → 曲线楼梯 → 悬挑回廊 → 主卧套房。

## 方案二：屋中小镇 · Y 字空中巷 Loft

**定位**：四口之家长期居住  
**面积与层高建议**：约 140–170 ㎡，净高约 6.8 m  
**配置**：3 卧、2.5 卫、1 个兴趣房、1 个儿童公共作业厅

### 建筑与布局

- 建筑外壳是一座完整挑空大厅，内部的三间卧室被设计成带斜屋檐轮廓的“屋中小屋”。
- 一层全部用于共同生活：家庭玄关、U 形开放厨房、六人圆餐桌、客厅、双面壁炉、音乐／手作兴趣房、洗衣房和食品储藏间。
- 中央楼梯从餐厅与客厅之间起步，在半层形成家庭留言平台，随后分成 Y 字两支。
- 左支只通向父母套房，包含主卧、步入式衣帽间和主卫。
- 右支通向儿童翼，包含两间独立儿童房、Jack-and-Jill 共用卫生间和公共作业厅。
- 三张床均避开挑空区的直接视线，卧室入口错位布置；儿童翼采用实体矮墙与圆角扶手。

### 核心空间语言

Y 字楼梯是一条向上分叉的“空中街道”，把公共生活与两组私密居住单元连接起来。二层三间卧室拥有不同高度的小屋檐，整套住宅像一个家庭住进了一座温暖的小镇。

### 生活动线

入户 → 家庭玄关 → 厨房／圆餐厅 → 客厅与窗边早餐位 → 半层留言平台 → 左侧父母翼或右侧儿童翼；兴趣房可从公共区独立进入。

## 方案三：环坡星轨 Loft

**定位**：独居者或创作型情侣  
**面积与层高建议**：约 85–110 ㎡，净高约 5.8–6.2 m  
**配置**：1 间主卧、2 卫、1 个悬挑工作室、连续复合收纳

### 建筑与布局

- 住宅取消传统主楼梯，设置一条沿建筑四周缓慢上升的连续环形坡道。
- 一层从玄关进入一字形开放厨房；厨房台面的一端逐渐抬升，与坡道和双人餐吧自然连接。
- 挑空中心设置椭圆形围合客厅，坡道像室内丝带环绕客厅上升。
- 坡道中段悬出一间透明但可关闭的工作室，可同时看见城市和中央客厅。
- 坡道终点是面向落地窗的悬挑卧室平台，床后设置环形步入式衣帽间与主卫。
- 坡道下方按净高变化依次布置抽屉、食品柜、行李仓、家政柜和设备间；后侧另设一条隐藏式快捷楼梯。

### 核心空间语言

厨房台面、餐吧、坡道、工作台和卧室平台由同一条木质“星轨”连续生长出来。人在家中的移动不再是上下楼，而是一段逐渐升高、不断改变视野的空间漫游。

### 生活动线

入户 → 开放厨房 → 餐吧 → 中央客厅 → 沿窗环坡 → 半层工作室 → 卧室与衣帽间 → 后侧快捷楼梯 → 返回玄关。
