# 《生活收尾局》01｜她睡着以后

## 项目定位

- 平台：抖音
- 画幅：原生 9:16
- 时长：严格 24.0s，低于 30s 成本上限
- 形式：固定高位斜俯完整 LOFT，同一机位内发生四次局部状态变化
- 声音：无对白、无现场音、只在后期铺一条 BGM
- 核心信息：今天，先到这里
- 核心情绪：认出疲惫 → 感觉被照顾 → 允许自己休息

这不是“房间展示片”。头盔、湿鞋、工牌、亮着的电脑和凉掉的面负责让观众认出自己的生活；烘干、熄屏、加热和盖毯只负责让这一天比开头好一点。

## 文件结构

- script.md：24 秒易读脚本、时间轴和图生视频分段提示。
- video-spec.md：完整制作规格与分镜表。
- common-continuity.md：摄影机、人物、户型、道具和负面约束。
- image-prompts.md：四张锚点图的生成提示与连续性要求。
- anchors/00s-after-work-asleep.png：开场母图；雨夜、睡着、一天尚未收尾。
- anchors/06s-entry-drying.png：玄关暖光开始烘干雨具。
- anchors/13s-day-being-finished.png：电脑熄屏、手机充电、晚餐回温。
- anchors/20s-safe-asleep.png：积水消失、灯光变暗、毯子盖好、猫也睡着。
- audio/：后续放置统一 BGM。
- video/：后续放置生成片段与最终成片。

## 推荐制作方式

为了保住建筑稳定性，不建议让视频模型一次自由生成完整 24 秒。最省返工的方式是：

1. 00s → 06s：只处理雨幕、人物呼吸和玄关烘干。
2. 06s → 13s：只处理积水减少、电脑熄屏、手机充电和晚餐蒸汽。
3. 13s → 20s：只处理灯光变暗、毯子滑落覆盖和猫蜷起。
4. 20s → 24s：复用最终锚点，只保留雨幕、呼吸和极轻灯光呼吸；文案后期淡入。

三个生成片段首尾直接对齐即可，不加花式转场；最终只有两处拼接和一次静帧延长。

## 验收优先级

1. 建筑、楼板、楼梯、扶手、家具和摄影机完全稳定。
2. 女主始终熟睡，不起身、不睁眼、不换衣服。
3. 生活线索始终可读，不能被蒸汽、光效或字幕遮挡。
4. 雨只在窗外和玻璃表面，室内不能继续进水。
5. 宁可动作少，也不要房间漂移；宁可毯子不动，也不要人物畸变。

- 输出采用 1080×1920、30 fps、高画质 MP4。
