# 《日子正在发生》02｜周六睡懒觉

## 项目定位

- 合集：**日子正在发生**
- 当前单集：**周六睡懒觉**
- 核心句：**周六，慢一点醒来**
- 主角：一对年轻情侣；全片始终只有两位成年人
- 宠物：保留一只虎斑猫，只作安静的生活细节
- 平台：抖音，原生竖屏 `9:16`，30 fps
- 总时长：`60.0s`
- 生成拆分：`3 × 20.0s`，每段均低于模型 `30s` 上限

## 文件说明

- `00-layout-reference.png`：原户型、材质、家具与上帝视角参考；人物和时间状态不可直接沿用。
- `01-reference-image-prompt.md`：生成本集“周六上午、情侣在床上”的新首帧提示词。
- `common-continuity.md`：三段视频共同遵守的人物、空间、声音与剪辑连续性规范。
- `02-segment-01-wake-up.md`：00:00–00:20，男主醒来并走向卫生间。
- `03-segment-02-wash-up.md`：00:20–00:40，男主洗漱并走出卫生间。
- `04-segment-03-wake-her.md`：00:40–01:00，男主叫女主起床，最后一起再赖五分钟。
- `video-spec.md`：全片 master script 与 18 个分镜。

## 推荐生成顺序

1. 先依据 `01-reference-image-prompt.md` 生成 `01-couple-morning-bedroom-reference.png`。
2. 用该图作为第 1 段首帧，生成 `segment-01.mp4`。
3. 导出第 1 段最后一帧作为第 2 段首帧，确保“手搭上卫生间门把”动作连续。
4. 导出第 2 段最后一帧作为第 3 段首帧，确保“走出卫生间、转向床边”动作连续。
5. 三段画面生成时关闭随机配音和随机音乐；剪辑阶段统一加入同一套对白、BGM 与环境音母带。
6. 在 20.0s 与 40.0s 使用动作匹配硬切，不使用花哨转场。

## 最重要的限制

- 不能直接把 `00-layout-reference.png` 当本集首帧：原图是傍晚且有四个人，本集必须是上午且只有情侣两人。
- 不得出现儿童、第三位成年人、人物换脸、睡衣变化或重复人物。
- 三段不得分别随机生成声音；男声、女声与背景音乐必须各自来自同一份母带。
