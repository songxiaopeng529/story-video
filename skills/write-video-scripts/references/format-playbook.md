# Format Playbook

Load this reference when choosing a structure, estimating duration, or adapting a script across formats. Treat all ranges as planning heuristics, not platform limits.

## Choose a narrative pattern

| Format | Useful spine | Emphasize | Avoid |
|---|---|---|---|
| Short social video | Specific hook → tension or gap → rapid proof or steps → payoff → optional CTA | One idea, early relevance, frequent visual change | Multiple theses, long greetings, delayed context |
| Talking head or voiceover | Promise → orientation → 2–4 beats → takeaway | Speakability, cadence, concise examples | Essay syntax, unexplained jargon |
| Tutorial | Result preview → prerequisites → ordered actions → common mistake → completed result | Demonstrable actions, state changes, checkpoints | Hiding required setup, narrating obvious clicks |
| Explainer or educational | Question → model or mechanism → example → implication → conclusion | Accurate mental model, concrete analogy, evidence | Fact dumping, analogy presented as proof |
| Product demo | User problem → workflow → visible outcome → qualification → next step | Real interface or product behavior, verifiable value | Unsupported superlatives, feature lists without use |
| Advertisement | Audience tension → value proposition → proof → offer → CTA | Truthful differentiation, product visibility, single action | Fabricated scarcity, guarantees, fake testimonials |
| Interview or documentary | Human question → context → discovery → complication → insight → resolution | Authentic voice, evidence, scene texture | Invented quotes, omniscient claims without support |
| Narrative short | Setup → desire → obstacle → escalation → turn → consequence | Character action, subtext, cause and effect | Expository dialogue, unearned twist |
| Vertical microdrama | Immediate situation → relationship pressure → reveal or reversal → emotional button | Performance beats, entrances/exits, prop continuity | Too many characters, locations, or backstory beats |

## Budget duration

Start with the target duration, then reserve 10–25% for pauses, reactions, actions, transitions, and titles. Increase the reserve for dialogue, comedy, tutorials, demonstrations, or emotionally played scenes.

Use these rough spoken-language ranges only for a first estimate:

- Conversational English: about 130–160 words per minute
- Fast promotional English: about 160–180 words per minute, only if clarity survives
- Conversational Mandarin: about 220–300 Chinese characters per minute, excluding punctuation
- Deliberate or emotional delivery: reduce the relevant range by roughly 15–30%

Validate with a read-through whenever precise timing matters. Do not stretch delivery speed to rescue an overlong draft.

## Allocate beats

For a 60-second information-led video, start with this flexible budget:

| Beat | Approximate share |
|---|---:|
| Viewing reason / hook | 5–12% |
| Context or tension | 15–25% |
| Main development or proof | 45–60% |
| Payoff / takeaway | 10–20% |
| CTA, if needed | 5–10% |

For narrative work, allocate by dramatic action instead of marketing beats. Give the turn and consequence enough screen time to register.

## Adapt across platforms

Adapt behavior, not just dimensions:

- For vertical feeds, make faces, hands, objects, and text readable in a narrow frame. Avoid critical action at the extreme edges.
- For long-form video, add section-level open loops, evidence, examples, and breathing room; do not simply slow a short script down.
- For search-led content, answer the query early and make the title promise explicit in the opening.
- For sound-off contexts, preserve comprehension with selective captions and visible state changes.
- For entertainment-led contexts, let character desire, surprise, or pattern carry the information instead of announcing every lesson.

Verify current platform specifications separately when the user needs exact upload limits, ad-policy compliance, safe zones, or technical delivery settings.
